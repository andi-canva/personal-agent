## Topic Vocabulary

Standard topic tags used in `topics:` frontmatter. Every file should use 1-3 of these. Customize this list for your domain.

| Topic | Covers |
|-------|--------|
| `product-craft` | Evals, PRDs, tool contracts, prototyping, PM methodology |
| `strategy` | Systems thinking, personalization, multi-channel, frameworks |
| `leadership` | Delegation, hiring, team ops, org design |
| `customer-experience` | Support metrics, resolution rates, quality, automation |
| `technical` | Architecture, integrations, infrastructure, tooling |
| `team` | Hiring, onboarding, team dynamics, org design |
| `personal` | Health, habits, routines, personal development |
